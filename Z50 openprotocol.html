1. 개요

  • ESTIC Z50(MU50) / Z55(MAU55) 컨트롤러의 Open Protocol 고유 구현 사양입니다.
  • 이 문서에 없는 항목은 공식 Open Protocol 표준 사양을 따릅니다.
  • 대상 펌웨어: MU50 MA1680 / MAU55 MI2150
  • 용어 구분: 문서 개정(Rev. 003)과 MID Revision(Rev 1/2)은 별개입니다.

2. 통신 프로토콜 및 메시지 구조

  • 워크그룹(Workgroup) 단위로 독립 제어합니다.
  • 워크그룹당 TCP 포트 1개 고정, 포트당 동시 연결 최대 2개입니다.
  • 전 워크그룹 공통: 전송 포맷 ASCII, 메시지 종료 코드 NUL (0x00).

5. ESTIC 전용 동작 로직

  • 전체 락(Lock): MID 0042/0043은 축 단위가 아니라 워크그룹 전체에 즉시 적용됩니다 (축별 개별 무효화 불가).
  • 프로그램 정보: MID 0011/0015는 해당 워크그룹 내 정보·변경 일시만 송신합니다.

6. 트레이스 커브 데이터 (MID 0900)

ACK 흐름 제어

MID 0008 구독 (전송 옵션 = 0 고정)
↓
MID 0900 수신
↓
MID 0005 ACK 송신
↓
다음 MID 0900 수신 가능
주의사항
  • MID 0900 전송 후 MID 0005 수신 전까지 다음 전문을 보내지 않습니다. 무시하고 연속 요청하면 버퍼 오버플로우가 발생합니다. ACK 타임아웃·재전송 확인
  • MID 0008 구독 시 전송 옵션은 0(새 데이터만) 고정입니다. 필드명 확인
  • 결과 0점이어도 헤더 포함 MID 0900 전문이 송신됩니다. 렌더링 전 Point Count 필드를 반드시 검증하세요.

전송 한계

  • 최대 전송 9,999 Bytes / 5,000점 미만 / 정밀도 0.5ms. 샘플은 2바이트 바이너리이며 Coefficient로 물리값 변환합니다.
  • 9,999 Bytes 한도의 범위(헤더·PID 포함 여부)와 2장 1004 Bytes 한도와의 관계 확인 필요
