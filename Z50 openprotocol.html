05

에스티크 전용 동작 로직

  • –전체 락(Lock): MID 0042/0043 → 축 단위 아닌 워크그룹 전체에 즉시 적용 (축별 개별 무효화 불가)
  • –프로그램 정보: MID 0011/0015는 해당 워크그룹 내 정보·변경 일시만 송신

MID 0061 (Rev 1)

Cell ID="0001", Channel ID="01", Batch Size/Counter="0000", Batch Status="2"

MID 0065 (Rev 2)

  • Job ID="0000", Batch Size/Counter="0000", Batch Status="2"
  • Tightening Error Status="0000000000"
  • Tool Serial Number = 14 Bytes Space

MID 0101 (멀티 스핀들)

  • Field ID 1~17: 1번 축 데이터
  • Field ID 18~: 그룹 내 전체 유효 축 데이터 통합 (축切り 상태 포함)

06

트레이스 커브 데이터 (MID 0900)

ACK 흐름 제어: MID 0900 전송 후 MID 0005 수신 전까지 다음 전문 대기 → 무시하고 연속 요청 시 버퍼 오버플로우

전송 옵션: MID 0008 예약 시 'Send alternatives' = 0 (새 데이터만) 고정

파싱 주의: 결과 0점이어도 헤더 포함 MID 0900 전문 송신됨 → 렌더링 전 Point Count 필드 반드시 검증

  • –최대 전송: 9,999 Bytes / 5,000점 미만 / 정밀도 0.5ms
