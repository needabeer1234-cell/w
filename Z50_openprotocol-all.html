1. 서론 (Introduction)

본 사양서는 Z50（MU50）용 오픈 프로토콜 사양 중 ESTIC 고유 사양에 대해 기재하고 있다.
본 문서에 기재되지 않은 사양에 관해서는 공식 Open Protocol 사양을 참조할 것.
본 문서에서 기재 대상으로 하는 것은 3.1 사용 가능 메시지(Available Message)를 참조할 것.

2. 프로토콜 (Protocol)

2.1 TCP/IP

사용하는 프로토콜은 TCP/IP이며, 접속 가능한 포트 번호는 다음과 같다.

  • 워크그룹 A : 4545
  • 워크그룹 B : 4546
  • 워크그룹 C : 4547
  • 워크그룹 D : 4548

동일한 포트 번호로 한 번에 최대 2개의 접속을 받을 수 있다.

2.2 시리얼 ASCII 프로토콜 (Serial ASCII protocol)

시리얼 ASCII 프로토콜은 지원하지 않는다.

2.3 메시지 구조 (Message structure)

통신 링크 상에서 전송되는 모든 정보는 ASCII 포맷으로 되어 있다.
하나의 메시지는 Header, Data Field, Message End의 3개 파트로 구성된다. 아래 섹션에 각 파트의 상세 내용을 나타낸다.

All information sent over the communication links is ASCII format.
A message consists of three parts, header, data field and message end. The sections below describe each part in greater details.

Header

Max 1004 bytes		 Message End
NUL (ASCII 0x0)
Length MID / Rev / … / Spare ….

3.2 ESTIC 고유 사항 (ESTIC-Specific Notes)

MID0008

예약에 대응한 MID는 MID0900뿐이다. (이 예약의 대응 상황에 대해서는 MID0900에 기재되어 있음)

MID0011

접속에 대응한 워크그룹 내에서 작성된 프로그램 번호에 관한 정보만 송신된다.

MID0015

Date of last change in parameter set setting（변경 일시）는 프로그램별이 아니라, 접속에 대응한 워크그룹의 파라미터 변경 일시가 송신된다.

MID0042 / MID0043

접속에 대응한 워크그룹 전체가 툴 잠금 상태 및 툴 잠금 해제 상태가 된다.

MID0060

접속에 대응한 워크그룹 내의 체결 축 수만큼 MID0061이 송신된다.

MID0061

MID0064의 Header의 Spindle ID로 지정한 축의 MID0065 전문이 송신된다.

전문 송신
1개 전문은 9999바이트 이하여야 하므로, Header 부분과 PID 부분을 포함하여 9999Byte 이하가 되도록 한다. 최대라도 5000점 미만의 정보가 된다. 이 5000점 미만은 체결 정지까지의 시간적으로 가장 마지막 부분이다.
1개의 전문을 송신한 후 Open Protocol Integrator 측에서 MID0005 송신을 기다린 후, 다음 MID0900 전문을 송신한다. (현재로서는 수 초간 대기가 타임아웃되면 송신하는 사양으로 하고 있으나, 앞으로도 이 동작을 보장하는 것은 아니다)
여러 단계로 구성된 체결에서 여러 단계가 출력 대상인 경우에는 연결된 커브 데이터를 출력한다. 단, MID0900에서는 시간 정보가 항상 등간격이어야 하므로, 첫 번째 단계를 기준으로 한 시간의 근사 위치에 커브를 출력한다. (이로 인해 MS0703 토크 커브 스캔 타임의 최대 1/2의 시간 오차가 발생할 가능성이 있다. 다만, 내부적으로는 0.5ms 정밀도로 계측을 수행하기 때문에, 스캔 타임을 0.5ms로 한 경우에는 오차가 발생하지 않는다.)
MID0900의 데이터는 다른 것과 비교하여 압도적으로 크기 때문에, 필요한 프로그램·단계에 한정하여 출력하는 것을 권장한다.

출력 판단
아래 판단으로 MID0900 전문을 출력한다.

  • MID0008에 의한 예약이 실시되고, 예약을 한 통신이 계속되고 있을 것
  • 대상이 되는 축이 축 분리 지령 중이 아닐 것
  • 시스템 파라미터의 MS0706 토크 커브 자동 취득이 "ON"으로 되어 있을 것
  • 대상이 되는 체결 프로그램에 대해 출력 설정의 MID0900 출력이 "있음"으로 되어 있을 것
    ※초기값은 "없음"이므로 설정이 필요함
  • 대상이 되는 체결 프로그램의 해당 ID의 축 할당 설정이 "사용"으로 되어 있을 것
  • 대상 단계의 기능이 "가체결", "본체결", "풀름"일 것
  • 대상 단계의 설정 "MP0204/MP0304/MP0404 토크 커브 취득"이 유효할 것

※또한, 체결 프로그램이 유효하다고 판단된 시점에 MID0900 전문은 출력되므로, 단계 실행 결과에 따라 출력 대상이 0점이 된 경우에도 커브 점수가 0점인 MID0900 전문을 송신한다.
